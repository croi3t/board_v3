# JAHIS フォーマット文法完全一致計画 (v17)

「見本データ」と「ツール生成データ」の差異をゼロにし、お薬手帳アプリの厳格なチェックを通過させます。

## ユーザー確認事項
- **アレルギー・副作用の入力**: 1行目にアレルギー、2行目以降に副作用…という順で見本に合わせますが、現在のように自由入力で大丈夫でしょうか。
- **用量の解析**: 「90日分」や「14枚」といった用法欄の末尾の数値を自動で抽出し、JAHISの数値項目に正しくセットするようにロジックを強化します。
- **医師情報の整理**: 見本に合わせ、レコード15を廃止し55のみにします。

## 変更内容

### app.js (CSV生成ロジックの刷新)
1. **Record 2 (History/Allergy)**:
   - 1行目を「1:アレルギー」、2行目以降を「2:副作用等」として出力するようにルール化。
2. **Record 55 (Doctor)**:
   - レコード15を削除し、55（診療科併記）のみで見本と一致させる。
3. **Record 301 (Usage) の詳細化**:
   - 用法テキストから「数量(90)」「単位(日分)」「用法区分(1)」「数量区分(1)」を抽出し、見本の `90,日分,1,1` の構造を再現。
4. **処方ブロックの順序変更**:
   - `201(薬品) -> 281/291(メモ) -> 301(用法)` の順序で出力。
5. **メモのレコード振り分け**:
   - 「一般：」や「変更前：」は281へ。「飲食物）」を含む場合は291へ自動振り分け。

## 検証計画
- データプレビューの内容が、ユーザー様から提示された「見本データ」の構造と目視で一致することを確認します。
- カンマの数と位置がすべてのレコードで正確かを確認します。
